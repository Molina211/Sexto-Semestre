# Bloque IP inicial

## $192.150.128.10/21$

| Direccionamiento | Descripción      |   192    |   150    |    128     |     10     |     |
| :--------------: | ---------------- | :------: | :------: | :--------: | :--------: | :-: |
|  192.150.128.10  | Dirección        | 11000000 | 10010110 | 10000*000* | *00001010* |     |
|  255.255.248.0   | Máscara          | 11111111 | 11111111 | 11111*000* | *00000000* |     |
| 192.150.128.0/21 | Dirección de red | 11000000 | 10010110 | 10000*000* | *00000000* |     |


- $/21$ - bits de host: $$32 - 21 = 11$$
- $2^{11} = 2048$ direcciones totales.
- Direcciones utilizables $$2^{11} - 2 = 2046$$ (se restan red y broadcast). 

Comparación con los 590 dispositivos que se buscan cubrir:

- Hosts útiles disponibles: $2046$
- Hosts requeridos: $590$
- Direcciones sobrantes: $$2046 - 590 = 1456$$

# Servicios

| Servicio | Función                     | Puerto         | Ubicación                        |
| -------- | --------------------------- | -------------- | -------------------------------- |
| **DHCP** | Asignar IPs automáticamente | 67/68 (UDP)    | Subred local o central con relay |
| **HTTP** | Servicio web                | 80 / 443 (TPC) | Infraestructura o DMZ            |
| **DNS**  | Resolver nombres ↔ IP       | 53 (UDP)       | Infraestructura                  |
| **FTP**  | Transferencia de archivos   | 20 / 21 (TCP)  | Infraestructura                  |
| **SMTP** | Envío de correo             | 25 / 587 (TCP) | Infraestructura                  |
